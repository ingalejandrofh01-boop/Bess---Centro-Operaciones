# Centro de Operaciones BESS — Skysense

Sitio web desplegado en GitHub Pages.

## Instrucciones de despliegue

1. Sube el contenido de este ZIP a un repositorio de GitHub
2. Ve a **Settings → Pages**
3. En "Source", selecciona la rama `main` (o `master`) y la carpeta `/ (root)`
4. Haz clic en **Save**
5. Tu sitio estará disponible en `https://<tu-usuario>.github.io/<nombre-repo>/`
